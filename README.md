# 🍶 주락 酒樂 — 합리적으로 사고, 즐겁게 마시다

**주락(酒樂)** 은 술을 **합리적으로 사고(재고·최저가)**, **즐겁게 마시는(콜키지프리 식당)** 것을 한곳에 모은 **조회 전용 무료 웹페이지**입니다.

### 🔗 바로 보기 → **https://ai-md.github.io/**

## 무엇을 볼 수 있나요

상단 **통합 검색창**(주락 딜 + 주락 픽을 한 번에)과 탭으로 이동합니다.

**🛒 주락 딜 — 트레이더스 주류 재고·최저가**
- 이마트 **트레이더스 전국 24개 지점**의 위스키·와인 등 주류 **재고·가격**
- **데일리샷 최저가 비교**(몇 % 저렴/비쌈)·**평점·리뷰·테이스팅 노트·Vivino**
- 🔥특가(데일리샷 20%↓)·지점별 재고·품절임박 표시 · **🗺 카카오맵 연동**
- 무료 알림(앱 푸시/이메일) — 특가·재입고·신상·품절임박·가격변동, **하루 2회(오전 9시·오후 6시)**

**🌟 주락 픽 — 트레이더스 밖 애호가의 명주**
- 트레이더스엔 없지만 소장 가치 있는 술을 **데일리샷 최저가·평점**으로 큐레이션
- 종류·정렬 필터 · 통합 검색 시 딜 결과 아래에 **픽 매칭도 함께 노출**

**🍽 콜키지 — 서울·수도권 콜키지프리 식당**
- 내 술을 가져가 마실 수 있는 **콜키지프리 식당**(카카오맵 평점 **3.5+** 선별)
- **지도 + 리스트** · 지역 필터 · **📍 내 주변**(현위치 가까운 순)
- 각 식당 **카카오맵 · 길찾기** 링크

**📚 알쓸신주 — 주류 지식**
- 위스키 종류·스카치 6대 산지·숙성/캐스크, 와인 포도품종·**지역별**·빈티지, 기타 주류·테이스팅 용어
- 상품 상세에서 **쉐리·올로로소·PX·캐스크스트렝스** 등 용어를 자동 감지해 풀이 제공

**🥃 AI 바텐더 — 취향 맞춤 추천 (회원)**
- **🥃 오늘의 추천 한 잔** — 내 조회 취향을 읽어 오늘 재고에서 딱 맞는 술 추천 (로컬 즉시 표시 → AI가 더 정밀하게 업그레이드)
- **🤖 AI 토킹바(혼술바 챗봇)** — 예산·기분·안주를 말하면 대화로 골라주는 회원 전용 바텐더 *(2026. 7. 11 정식 오픈)*

**🙋 회원(카카오 로그인) — 무료·선택**
- **⭐ 관심상품 워치리스트** · **💰 목표가** · **🍽 콜키지 즐겨찾기** 저장
- 닉네임 + 조회 취향(추천용)만 수집 · 실명 비노출 · 본인만 접근 · 탈퇴 시 삭제 · 로그인 없이도 기본 기능 무료

## 갱신 주기
- **주류 재고**: 매일 **저녁 1회** (트레이더스 영업시간 중)
- **데일리샷 가격·평점**: 매일 **아침**
- **알림 발송**: 하루 **2회**(오전 9시·오후 6시)
- **콜키지프리 식당 · 주락 픽**: **주 3회**(월·수·금)
